# 宠物素材与图标

## 当前形象

程序内置五只宠物，均为柔软立体的毛绒渲染风格：

- 小熊猫：red-panda.png，橙红毛、白色眉斑与脸颊、条纹大尾巴。
- 奶牛猫：cow-cat.png，黑白奶牛花纹、白色鼻梁与胸口。默认宠物。
- 柯基：corgi.png，黄白短腿、立耳、白色鼻梁。
- 熊猫：panda.png，白色身体、黑耳与黑色眼斑。
- 北极熊：polar-bear.png，纯白蓬松、圆耳、黑色爪垫。

每只宠物另配一张 -walk.png：透明背景 2×2 四帧步行图集。小熊猫、奶牛猫、柯基、熊猫四脚走路，北极熊保持两脚直立走路。

## 生成与处理

办公坐姿与步行图集以 `宠物形象设计/01-05` 设计稿为参考，使用内置 imagegen 生成，绿幕背景经色度抠图后输出真正 alpha 透明通道。

坐姿统一放入 1254×1254 透明画布：内容按高度约 1200 像素等比缩放、水平居中、底部对齐，保证切换宠物时视觉大小稳定。步行图集同样为 1254×1254，严格 2×2 等分，每格 627×627；四帧共用一个缩放比例，按脚底基线对齐并水平居中，不裁耳朵、尾巴和脚。白色毛发、尾巴与爪垫边缘已检查，没有保留绿色描边。

旧的三套宠物素材（橙猫、萨摩耶、旧版北极熊）已从程序中移除。旧配置中的 `cat` 自动迁移为奶牛猫，`samoyed` 迁移为柯基，`polar-bear` 继续对应新的北极熊，无法识别的值回退为奶牛猫。WinUI 3 版把 assets 文件夹随发布目录复制，启动时从程序目录读取坐姿与步行图集。

## 应用图标

app-icon.ico 和 app-icon.png 已同步改为新的五宠主题：奶牛猫与柯基共用一枚蓝色时钟，沿用原图标“两只代表宠物 + 时钟”的构图。图标保留 16、24、32、48、64、128、256 共七种尺寸，ICO 与 PNG 随 assets 目录分发；无外部字体或图片依赖。图标只呈现两只代表宠物，其余三只仍可在应用内切换。

## 最终生成规格

坐姿：侧面偏前的办公姿态，木桌、银色笔记本电脑、白色咖啡杯、木椅完整；无文字、无背景、真正 alpha 透明。角色必须与设计稿一致：小熊猫为橙红毛白脸和环纹尾，奶牛猫为黑白花色和白鼻梁，柯基为黄白短腿立耳，熊猫为黑白眼斑，北极熊为纯白圆耳。

步行：全部侧面朝右、水平脊背、四只脚在身体下方；小熊猫、奶牛猫、柯基、熊猫禁止后腿直立，北极熊保持两脚直立、前爪自然摆动。四帧为连续步行循环，比例和基线一致，每格独立留白。无桌椅、杯子、地面、网格或文字。
