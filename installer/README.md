# Windows 安装包

使用 Inno Setup 6.7.3 构建中文、当前用户安装程序。无需安装 .NET，支持 Windows 10 2004 及以上 x64，推荐 Windows 11 x64。Windows 10 尚未实机验收。

## 构建

```powershell
.\installer\build-installer.ps1 -CompilerPath 'C:\工具\Inno Setup 6\ISCC.exe'
```

默认先发布到 publish，再输出到相邻的“下班倒计时-安装包”目录。已有完整发布包可加 `-SkipPublish`；可指定 `-PayloadDir` 和 `-OutputDir`，避免覆盖正在运行的发布目录。编译器可通过 ISCC 环境变量指定。不会自动下载编译工具。

完整打包自包含发布文件（不含调试 PDB），校验微软签名的 VC++ x64 安装程序，生成 EXE 和 SHA256。编译器来自 https://jrsoftware.org/isdl.php；中文翻译来自 Inno Setup 6.7.3 官方仓库的 ChineseSimplified.isl，保留文件中的作者声明。

## 安装与升级

- 双击安装包，默认安装到 `%LOCALAPPDATA%\Programs\OffWorkWidget`，创建开始菜单快捷方式，可选桌面快捷方式。不会添加开机启动。
- 缺少 Microsoft Visual C++ x64 14.51.36247 或更高兼容运行库时，安装器调用随包携带的微软安装程序，系统会请求管理员授权；取消授权会阻止安装，而不是交付无法启动的程序。安装器本身保持当前用户权限。
- 新版运行中可以覆盖安装：通过命名事件请求程序保存并退出。更早的便携版不支持此信号时，先从托盘选择“退出”，再重试；不强行结束进程。
- 从 Windows“已安装的应用”卸载。卸载保留 `%LOCALAPPDATA%\OffWorkWidget` 中的设置、节假日缓存和隐私数据库。便携版和安装版使用相同数据目录，不能同时运行。
- 安装和运行日志可能包含当前用户名及路径；对外分享前检查。工资及密码不随安装包分发。
- 当前安装包未做发行者代码签名，首次下载后 Windows 可能显示未知发布者；正式公开分发建议使用代码签名证书。

## 验证边界

`-InstallerQATest` 生成文件名与 AppId 均不同的内部测试包，仅跳过运行库安装，以便在开发机验证安装、升级、卸载生命周期。不得分发该测试包。正式构建不定义该宏，运行库检测始终启用。

自动测试使用 OFFWORKWIDGET_TEST_DATA 指向隔离目录，避免触碰个人数据；安装程序也遵守隔离实例信号。干净系统的 VC++ 安装授权、重启路径和 Windows 10 兼容性需要虚拟机或对应机器补测。
